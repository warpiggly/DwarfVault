TUTORIAL — the corporate hall

Welcome to the Vault ⛏️

DwarfVault keeps your notes, links and snippets safe in a dwarven stronghold. This is the corporate hall — a clean, spreadsheet-style view of everything you forge. Follow the steps below and you'll be mining data like a seasoned dwarf. 🏔️

🏛️

Vault

A main database — your top-level folder (e.g. Work).

📦

Chest

A sub-sheet inside a Vault, shown as a bottom tab.

📜

Entry

One saved row: text + URL + the page's favicon.

Quick start

1

Forge a Vault 🔨

Open the Vault menu → ＋ New Parent, give it a name, and your first Vault appears in the picker on the left.

2

Add a Chest 📦

Use Vault → ＋ New Child (or the + tab at the bottom) to split a Vault into topic sheets. Switch between them with the bottom tabs.

3

Fill the grid ✍️

Double-click any cell to edit — or delete — the entry. A single click on a Text cell copies it, and on a URL cell opens the link in a new tab.

4

Find your treasure 🔎

Type in the Search box to filter the current sheet instantly, and hop between Vaults with the picker beside it.

Explore the hall

🧭 Navigating — the three stars & the switch

The three golden stars at the top move you between the corporate views:

⭐ Home — this spreadsheet grid, where you edit entries.
⭐ Schema — a map of how your Vaults and Chests connect (parent → child).
⭐ Tutorial — this page. 📖

The little switch in the top-right corner flips between the classic dwarven look and this corporate hall. Same data, two moods. 🎭

🗂️ The menu bar — Vault & Data

Vault menu — manage databases:

＋ New Parent new Vault · ＋ New Child new Chest · ✎ Rename rename the selected one · × Delete remove it forever ⚠️

Data menu — move things in and out:

⇩ Import CSV / ⇧ Export CSV back up a single sheet as a spreadsheet file.
🗃️ Import Full Vault / 📦 Export Full Vault back up a Vault with all its Chests in one JSON file.

🖱️ Save from any web page

Select text on any page → right-click → 📥 Save to Vault → pick a Vault. The text, its URL and the site favicon are stored together as a new Entry. 🏰

The Context Menu and Settings buttons in the menu bar let you bind favorites/links to the right-click menu and adjust general options like notifications. ⚙️

📊 Reading the grid

Each row is one Entry with four columns:

# the row number · Icon the source favicon · Text what you saved · URL where it came from.

Zebra striping keeps rows easy to follow, and hovering a row lights it with a soft golden glow. Empty rows invite you to start typing a new Entry. ✨

🔒 Everything is stored locally in your browser — nothing leaves your machine. Use Export now and then to keep a backup of your hoard.
